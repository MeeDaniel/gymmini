**Gymmini** — это умный асинхронный Telegram-бот для ведения дневника тренировок, учёта подходов и управления персональными упражнениями и шаблонами.

---

## 🌟 Ключевые особенности (MVP v1.0.0)

- **💬 Правило одного сообщения (Rule of One Message)**  
  Весь интерфейс бота функционирует внутри одного динамически обновляемого сообщения с поддержкой фотографий (`edit_message_text_or_caption`), не засоряя историю чата. Во всех диалогах и меню ввода предусмотрены кнопки **«❌ Отмена»**.

- **🏋️ Кастомные упражнения и типы нагрузок**  
  Поддержка 4 типов упражнений с российской локализацией:
  - **Силовое** (повторения и вес, напр.: `10x50`, `12 60.5`);
  - **Кардио** (дистанция и время, напр.: `2.5км 15мин`, `500м 45с`);
  - **Собственный вес** (количество повторений, напр.: `15`, `20 раз`);
  - **На время** (продолжительность выполнения, напр.: `60`, `1 мин 30 с`).  
  К каждому упражнению можно прикрепить фотографию. Встроена защита целостности БД: бот запретит удаление упражнения, если оно уже используется в истории или шаблонах.

- **📋 Шаблоны тренировок**  
  Создание и редактирование готовых программ тренировок (добавление/удаление упражнений, описания) с возможностью мгновенного старта тренировки в один клик.

- **🚀 Управление активной тренировкой и история**  
  - Запуск тренировки с необязательным вводом уточнения к названию (или кнопкой «Пропустить»).
  - Мгновенное добавление подходов в реальном времени с автоудалением сообщений пользователя.
  - Настройки тренировки: переименование, редактирование описания, изменение времени старта (с кнопкой **«🕒 Сейчас»**).
  - Индивидуальные заметки к упражнениям внутри тренировки.
  - Просмотр и редактирование истории прошедших тренировок.

- **📄 Интеграция Telegraph (Instant View)**  
  Для описаний упражнений, шаблонов или тренировок длиной более 300 символов бот автоматически создаёт красиво оформленную статью на **Telegra.ph** с преобразованием Markdown в HTML, которая открывается прямо в Telegram в режиме Instant View.

- **🧠 Умный парсер подходов (`src/bot/formatters.py`)**  
  Парсер автоматически распознаёт любые естественные форматы ввода пользователя (например, `"10x80"`, `"2.5км 15м"`, `"1ч 30мин 45с"`, `"15 раз"`) и аккуратно форматирует их при выводе.

## 🛠 Технологический стек

- **Язык**: Python 3.11+
- **Telegram API**: [aiogram 3.x](https://github.com/aiogram/aiogram)
- **База данных**: SQLite + [SQLAlchemy 2.0](https://www.sqlalchemy.org/) (асинхронный ORM `AsyncSession`)
- **Миграции**: [Alembic](https://alembic.sqlalchemy.org/)
- **Пакетный менеджер**: [uv](https://github.com/astral-sh/uv)
- **Тестирование**: `pytest`, `pytest-asyncio`

## 🚀 Быстрый старт

### 1. Предварительные требования
Убедитесь, что у вас установлен Python 3.11+ и пакетный менеджер **`uv`**:
```bash
pip install uv
```

### 2. Клонирование и установка зависимостей
```bash
git clone https://github.com/MeeDaniel/gymmini.git
cd gymmini
uv sync
```

### 3. Настройка окружения
Создайте файл `.env` в корневой директории проекта и укажите токен вашего бота (полученный у [@BotFather](https://t.me/BotFather)):
```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
DATABASE_URL=sqlite+aiosqlite:///./gymmini.db
```

### 4. Применение миграций базы данных
```bash
uv run alembic upgrade head
```

### 5. Запуск бота
```bash
uv run python main.py
```

## 🧪 Запуск тестов

Проект покрыт автоматическими асинхронными интеграционными и модульными тестами:
```bash
uv run pytest
```

Набор тестов проверяет:
- Корректность CRUD-операций сервисов (`tests/test_services.py`);
- Работу парсера подходов и единиц измерения (`tests/test_parser.py`);
- Логику создания тренировок и заметок (`tests/test_new_logic.py`);
- Наличие и работу кнопок отмены во всех меню (`tests/test_cancel_buttons.py`);
- Защиту целостности базы данных при попытке удаления используемых упражнений (`tests/test_exercise_deletion.py`).

## 📁 Структура проекта

```
gymmini/
├── alembic/              # Миграции базы данных Alembic
├── docs/                 # Архитектурная и техническая документация
├── media/                # Загруженные пользователями изображения упражнений
├── src/
│   ├── bot/              # Модули Telegram-бота (aiogram)
│   │   ├── handlers/     # Обработчики команд, меню, CRUD, тренировок и истории
│   │   ├── callbacks.py  # Фабрики callback-данных
│   │   ├── formatters.py # Парсер и форматирование подходов и единиц измерения
│   │   ├── keyboards.py  # Генераторы инлайн-клавиатур
│   │   ├── messages.py   # Локализация и шаблоны сообщений
│   │   ├── states.py     # FSM-состояния aiogram
│   │   └── utils.py      # Хелперы редактирования сообщений и интеграция Telegraph
│   ├── db/               # Асинхронная сессия БД и конфигурация SQLAlchemy
│   ├── models/           # ORM-модели (User, Exercise, Workout, WorkoutNote, ExerciseNote, Set)
│   └── services/         # Сервисный слой и бизнес-логика (работа с БД, проверки целостности)
├── tests/                # Модульные и интеграционные тесты pytest
├── CHANGELOG.md          # История изменений проекта
└── main.py               # Точка входа приложения
```
