# Инструкция по комплексному тестированию бота Gymmini

Эта инструкция описывает полные сценарии тестирования всех текущих возможностей бота. При изменениях функционала сверяйтесь с ней, чтобы ничего не сломать.

## 1. Главное меню и старт работы
1. Отправьте `/start`.
2. Убедитесь, что вы получаете приветственное сообщение ("Привет, {name}! Твой профиль Gymmini готов к работе.") и главное меню.
3. Проверьте наличие всех 4 кнопок:
   - 🏋️ Начать тренировку
   - 📋 Шаблоны Тренировок
   - 🏃 Мои Упражнения
   - 📖 История тренировок

## 2. Управление Упражнениями (Мои Упражнения)
1. В главном меню нажмите `🏃 Мои Упражнения`.
2. **Создание**:
   - Нажмите `➕ Создать упражнение`.
   - Введите название.
   - Выберите тип (Силовая, Кардио, Свой вес, На время).
   - Отправьте фотографию (картинка должна подгрузиться) ИЛИ нажмите `Пропустить`.
   - Бот должен сообщить об успешном создании и вернуть в главное меню.
3. **Просмотр и Редактирование**:
   - Снова зайдите в `Мои Упражнения`. Найдите созданное упражнение и нажмите на него.
   - Должна появиться фотография (если была загружена) и текстовое описание.
   - Нажмите `✏️ Изменить`, введите новое название и проверьте, что оно сохранилось.
4. **Удаление**:
   - В карточке упражнения нажмите `🗑 Удалить`.
   - Карточка должна исчезнуть, а бот – показать обновленный список упражнений, без ошибок о "message to edit not found".
   - Нажмите `🔙 Назад` из списка упражнений – вы должны вернуться в главное меню.

## 3. Шаблоны Тренировок
1. В главном меню нажмите `📋 Шаблоны Тренировок`.
2. **Создание шаблона**:
   - Нажмите `➕ Создать шаблон`.
   - Введите короткое название (например, "День Ног").
   - Бот должен сразу перевести вас в меню "Управление упражнениями" этого шаблона (без двойных сообщений об успехе).
3. **Управление упражнениями в шаблоне**:
   - Нажмите `➕ Добавить упражнение`. Откроется список ваших упражнений. Выберите одно (например, созданное ранее).
   - Бот должен сообщить "Упражнение добавлено!" и вернуть к меню управления с обновленным списком.
   - Добавьте еще 1-2 упражнения.
   - Проверьте кнопки `⬆️` и `⬇️` – порядок упражнений должен меняться.
   - Проверьте кнопку `❌` – упражнение должно исчезнуть из шаблона.
4. **Навигация**:
   - Нажмите `🔙 Назад` из управления упражнениями, чтобы выйти в просмотр шаблона.
   - Проверьте кнопку `🔙 Назад` из просмотра шаблона, чтобы выйти к списку шаблонов.

## 4. Активная Тренировка (Старт и выполнение)
1. В главном меню нажмите `🏋️ Начать тренировку`.
2. Выберите созданный шаблон.
3. Бот предложит ввести время начала. Нажмите кнопку `Сейчас`.
4. **Проверка зависания**:
   - Сообщение с выбором времени должно *измениться* на заголовок "🔥 Активная тренировка" (старое сообщение не должно оставаться, новое не должно дублироваться).
5. **Запись подходов**:
   - Выберите упражнение из списка активной тренировки.
   - Отправьте в чат данные (например: `10x50` для силовых, `15` для собственного веса, `10 км 30 мин` для кардио).
   - Бот должен ответить "Подход добавлен..." и обновить список подходов в этом же сообщении.
6. **Добавление нового упражнения "на лету"**:
   - В активной тренировке нажмите `🔙 Назад к тренировке`.
   - Нажмите `➕ Добавить упражнение` (из списка глобальных упражнений).
   - Добавленное упражнение должно появиться в списке текущей активной тренировки.
7. **Завершение**:
   - Вернитесь к списку упражнений активной тренировки.
   - Нажмите `⏹ Завершить тренировку`. Бот должен поздравить с успешным завершением и перевести в главное меню.

## 5. История Тренировок
1. В главном меню нажмите `📖 История тренировок`.
2. Должна появиться завершенная только что тренировка.
3. Нажмите на нее, проверьте список подходов.
4. Нажмите `▶️ Продолжить` (или вернуться к тренировке).
5. Тренировка снова перейдет в активный режим, где можно дописать подходы.
6. В конце снова нажмите `⏹ Завершить тренировку`.
